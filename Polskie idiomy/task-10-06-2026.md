## Структура сторінки

### 1. Hero section

Створи сучасний вступний блок:

- назва: `Polskie idiomy`
- підзаголовок українською;
- короткий опис англійською;
- 3–4 learning outcomes;
- красивий сучасний дизайн у стилі language-learning app.

Приклад змісту:

```text
Вивчай польські ідіоми через приклади, пояснення, аудіо та інтерактивні вправи.
Learn Polish idioms through examples, Ukrainian and English explanations, audio practice, and quizzes.
```

### 2. Idiom cards

Створи картки для кожної ідіоми.

Кожна картка повинна мати:

- польську ідіому;
- українське пояснення;
- English explanation;
- приклад польською;
- переклад українською;
- переклад англійською;
- кнопку “Show / Hide explanation”;
- audio player, якщо відповідний MP3-файл підходить до цієї ідіоми.

Якщо неможливо точно визначити, який MP3 до якої ідіоми належить, створи окремий розділ “Audio practice” з усіма 20 аудіофайлами.

### 3. Audio practice section

Створи окремий розділ:

```text
Audio practice / Практика аудіювання
```

Для кожного MP3-файлу зроби красиву аудіокартку:

- номер уроку;
- назва файлу;
- audio player;
- коротке поле для нотаток учня;
- кнопка “Mark as practiced”.

Приклад:

```html
<audio controls>
  <source src="Polskie idiomy 01.mp3" type="audio/mpeg">
</audio>
```

Але шлях до файлів має бути правильний відносно створеної сторінки.

### 4. Quiz section

Створи інтерактивний quiz на основі матеріалів з HTML-файлів.

Види завдань:

- multiple choice;
- match idiom to meaning;
- choose correct idiom for situation;
- fill in the blank;
- true / false.

Вимоги:

- миттєва перевірка;
- показ правильної відповіді;
- score counter;
- progress bar;
- reset quiz button;
- vanilla JavaScript only.

### 5. Flashcards section

Створи flashcards для повторення.

Кожна flashcard:

- front: польська ідіома;
- back: українське та англійське пояснення;
- кнопка flip;
- next / previous;
- progress indicator.

### 6. Speaking drill section

Створи розділ для усного тренування:

```text
Speaking drill / Тренування мовлення
```

Для кожної вправи:

- ситуація українською;
- situation in English;
- завдання: використати польську ідіому;
- кнопка “Show model answer”;
- модельна відповідь польською;
- короткий переклад.

### 7. Common mistakes section

Створи блок типових помилок:

- неправильний дослівний переклад;
- правильний польський варіант;
- коротке пояснення українською;
- коротке пояснення англійською.

### 8. Final revision section

Створи фінальний блок повторення:

- короткий список головних ідіом;
- mini final quiz;
- checklist для самоперевірки;
- кнопка “Start quick revision”.

- Жодних зовнішніх бібліотек.

```text

CTA: Start lesson
```
